# Tokyo Streets

Браузерный MVP Japanese Racing World по концепту v0.2: ночная тактическая touge-дуэль в 2D-изометрии. Русский интерфейс. Реальные названия автомобилей и деталей по запросу автора.

## Запуск

Требуется Python 3. Никаких npm-зависимостей, сборки, аккаунтов или ключей.

```bash
git clone https://github.com/AlexSapronov/Tokyo_Streets.git
cd Tokyo_Streets
python3 -m http.server 5173
```

Открыть **http://localhost:5173**. На Windows вместо `python3` можно использовать `py`. Если установлен Node и Python 3, доступна команда `npm run dev`. Не открывать HTML через `file://`: ES-модулям нужен HTTP-сервер. Проект также можно раздавать любым статическим веб-сервером из корня репозитория. Публикация и GitHub Pages не включены.

## Первый заезд

1. В гараже выбрать машину и пилота; купить и установить детали при необходимости. Старт: AE86 и ¥80 000. Все три пилота доступны сразу.
2. На экране заезда выбрать покрытие и нажать «На старт».
3. На каждом из восьми секторов выбрать карту и изучить прогноз. Затем нажать «Исполнить сектор».
4. Посмотреть прохождение. Пауза останавливает воспроизведение; 2× действует со следующего сектора. Пробел переключает паузу, когда фокус вне кнопок и полей.
5. После финиша изучить причины результата, получить награду и обслужить машину. Отчёт можно скачать в JSON.

## Что реализовано

- Один закрытый горный маршрут «Спуск Харуна», 2.77 км, восемь секторов: прямые, быстрые повороты, шпильки и связки. Три режима влажности.
- Toyota Sprinter Trueno AE86, Toyota Chaser Tourer V JZX100, Mitsubishi Lancer Evolution VI. Масса, мощность, привод, сцепление, тормоза, охлаждение и состояние действительно влияют на расчёт.
- Три оригинальных пилота: дисциплина, агрессия и хладнокровие; разные параметры и характерные карты.
- 13 общих карт, 3 карты характера и 1 карта оборудования. Набор выбранного пилота открыт целиком: 14 карт изначально, 15 с HKS. Никакого случайного добора. Фильтры скрывают только визуальную категорию.
- Условия применения, концентрация, откат, нагрев, износ, влияние изучения соперника на следующий сектор, позиционные окна для слипстрима и защиты.
- Соперник выбирает из того же набора и использует тот же расчёт без скрытых преимуществ.
- Шесть деталей: Yokohama, Brembo, HKS, CUSCO, TEIN и облегчение с RECARO. Детали покупаются и устанавливаются отдельно на каждую машину. Снятые детали остаются в гараже.
- Деньги, покупка машин, износ, сервис, Street Credibility, история и лучшее время. За победу ¥18 000, за завершение без победы ¥7 000. Ничья считается завершением без победы. За выход до финиша награды нет.
- Векторное окружение на Canvas: горы, лес, мокрая дорога, фары, дождь и движущиеся машины. Все визуальные элементы нарисованы кодом; сторонние изображения и генерация не использованы.
- Автосохранение карьеры в `localStorage`, с защитой от повреждённых данных. При недоступном хранилище игра работает до закрытия страницы и показывает уведомление.

## Границы прототипа

Это проверка ядра, а не весь концепт. Пока нет свободного вождения, полной карты Японии, редактора маршрутов, команды, организатора чемпионатов, мультиплеера, дрэга, дрифта, звука и официальных серий. Official Reputation отображается как отдельная будущая ветка и пока не растёт.

Сохранение локальное для браузера и адреса сайта. Незавершённый заезд после перезагрузки начинается заново; деньги и детали сохраняются. При уходе со страницы во время дуэли браузер показывает предупреждение. Лучшее время объединяет разные сборки и погоду, поэтому не служит сравнительным рейтингом.

Маршрут и модели машин визуально стилизованы; карта не воспроизводит геометрию реального перевала. Анимация показывает общий прогресс сектора и разрыв, а не точную колёсную физику или индивидуальную траекторию каждого манёвра. Скорость анимации не меняет результат. Подробности упрощённого расчёта — в [docs/SIMULATION.md](docs/SIMULATION.md).

## Проверка

Node.js 22 или новее:

```bash
npm run check
npm test
```

Тесты проверяют детерминированность, все сочетания машин/пилотов/погоды, одинаковые возможности AI, ограничения карт, влияние оборудования, ресурсы и сохранения. GitHub Actions запускает эти же проверки без установки зависимостей.

## Структура

- `src/data.js` — контент и стабильные ID машин, пилотов, деталей и карт.
- `src/engine.js` — чистая детерминированная симуляция и AI.
- `src/scene.js` — Canvas-сцена и воспроизведение.
- `src/storage.js` — версия, валидация и хранение карьеры.
- `src/app.js` — интерфейс, экономика и игровой цикл.
- `tests/engine.test.js` — проверки механик и сохранений.
