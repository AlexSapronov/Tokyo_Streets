# Tokyo Streets — Garage Expansion 0.9.1

Браузерная тактическая гоночная игра по концепту Japanese Racing World v0.2: изометрическая Япония, открытый набор карт, машины, пилоты и инженерные решения. Русский интерфейс. Реальные названия автомобилей и деталей по запросу автора.

## Запуск и обновление

Нужен только Python 3. Сборка, npm-зависимости, ключи и аккаунты не требуются.

```bash
git clone https://github.com/AlexSapronov/Tokyo_Streets.git
cd Tokyo_Streets
python3 -m http.server 5173
```

Открыть **http://localhost:5173**. На Windows использовать `py -m http.server 5173`. Альтернативно `npm run dev`, если установлен Node и доступна команда `python3`. Не открывать `index.html` через `file://`: ES-модулям нужен HTTP-сервер.

Уже установлена v0.1:

```bash
cd Tokyo_Streets
git pull --ff-only origin main
```

Обновить страницу через **Ctrl+F5**. Открывать на том же адресе, что раньше: сохранения привязаны к браузеру, хосту и порту. Старые деньги, машины, детали, счётчики и история переносятся автоматически. Старые заезды не получают выдуманные повторы: в v0.1 не сохранялись решения и времена секторов.

## Исправление запуска 0.9.1

Устранена загрузка несовместимых версий ES-модулей после обновления. Например, новый интерфейс импортировал `recoveryService`, а браузер мог использовать старый `garage.js` без этого экспорта — загрузка прерывалась до появления обработчиков меню. Теперь import map закрепляет все 21 модуль за одним идентификатором версии и хеша содержимого. Стили получают тот же идентификатор. Это работает при запуске как из корня, так и из подпапки.

Если импорт или начальный запуск всё же завершится ошибкой, вместо пустого экрана показываются описание, текст ошибки и кнопка перезагрузки. Сохранения при этом не очищаются. После установки исправления обновить страницу через Ctrl+F5.

Для разработки: после изменений исходников/стилей выполнить `npm run release:assets` и закоммитить обновлённый `index.html`. `npm run check` и CI проверяют соответствие хеша исходникам. Для обычного запуска по-прежнему достаточно Python: Node и сборщик игроку не нужны.

## Что нового в 0.8

Общий баланс всей игры, а не только дрэга:

- **Последствия траектории.** Позднее торможение, ранний апекс и защита ухудшают скорость выхода; силовой выход её сохраняет. Скорость меняет следующий сектор. Перенос веса учитывает массу машины.
- **Общая нагрузка атак.** Разные агрессивные карты накапливают напряжение 0–6: растут стоимость концентрации и риск, при высокой нагрузке — потеря темпа. Замена одной атаки другой не сбрасывает напряжение. Спокойный темп и восстановление уменьшают его; экспоненциальный штраф повторов сохранён.
- **ИИ учитывает сход.** При выборе карты он оценивает ожидаемую цену аварии по текущему фокусу, нагрузке и оставшемуся горизонту. Будущий бросок ему неизвестен. Аки охотнее принимает риск, Юи осторожнее.
- **Классы сборок.** CLUB / SPORT / EXPERT зависят от мощности/массы и деталей. Соперник в дорожной дуэли и дрэге соответствует классу; повреждение не понижает класс. Медали Time Attack имеют фиксированный эталон для каждого класса.
- **Экономика.** Новая карьера: ¥18 000. Обычные выплаты: 55% базовой ставки × класс (0.8 / 1 / 1.2); дрэг дополнительно ×0.45. Повторение одного события снижает ставку до 50%, отдельно по каждому событию. Сервис — ¥450 за 1 п.п. состояния, штатный износ сильнее влияет на состояние. Существующие деньги и покупки сохраняются.
- **Допуск и восстановление.** Для дуэли нужно 45% состояния, для Time Attack, дрэга и дрифта — 55%. При состоянии ниже 60% доступен аварийный ремонт до 60%: имеющиеся деньги идут в оплату, остаток покрывается из половины будущих призовых. Долг сохраняется; тупика при нулевом кошельке нет.
- **Командные пилоты развиваются.** Каждые пять стартов в команде дают +0.0025 навыка и +1 максимального фокуса, максимум шесть уровней, навык не выше 0.995. Доверие определяет глубину планирования: один, два или три сектора. Приказы, характер и зарплата сохраняют значение.

Под приборами — отдельная крупная полоса фокуса с числом, цветом и предупреждением при низкой концентрации. Внизу каждого экрана — DEBUG-кнопки **«Открыть всё»** (все покупки, события и контракты, состояние 100%, ¥1 000 000; выбранные сборки сохраняются) и **«Сбросить всё»** (новая карьера после подтверждения).

Рекорды нового баланса: дорога `4`, дрэг `drag-2`, дрифт `drift-2`. Старые записи доступны как архивные повторы и не заменяют новые призраки. Исследование всей игры: `npm run balance:all`; детали формул и ограничений — [docs/BALANCE.md](docs/BALANCE.md).

## Что нового в 0.7

Результат каждого действия теперь имеет случайный разброс исполнения. Одинаковые правила действуют для игрока, соперника и нанятого пилота. Берётся абсолютный фокус **до** действия: восстановление стабилизирует следующий ход. Порог допуска карты, стоимость фокуса и штрафы за спам остаются предсказуемыми.

| Фокус | Базовый диапазон ошибки исполнения |
| --- | --- |
| 100 и выше | ±0,8% |
| 75 | ±1,75% |
| 50 | ±4,6% |
| 25 | ±9,35% |
| 0 | ±16% |

Диапазон растёт квадратично по мере истощения фокуса. В дорожных гонках ошибка меняет время сектора. В дрэге она меняет фактический прогрев и стартовые обороты, реакцию, реализуемую тягу/сцепление и паузы переключений; на длинных дистанциях последствия распространяются на нагрев и отсечки. В дрифте меняются точность линии, угол, темп и итоговая судейская оценка; возможен выход за предел управляемости. Эти проценты описывают входную ошибку, а не гарантированный диапазон итоговых секунд или баллов. Штатная мощность автомобиля не меняется.

Прогноз и планировщик ИИ используют базовую симуляцию без броска и не видят будущую случайность. Фактический результат определяется после выбора карты; просмотр карт и расчёт плана ничего не перебрасывают. В интерфейсе прогноз показывает качественную стабильность исполнения, после действия журнал объясняет отклонение. Игрок и ИИ получают независимые броски по одной формуле.

Каждый новый заезд получает seed. Seed, номер сектора и сторона задают воспроизводимый бросок; конкретная карта в seed не входит. Лучший заезд сохраняет seed и версию исполнения вместе с уже записанными временами, телеметрией и оценками. Повтор читает запись и не запускает случайность заново. Старые сохранения и повторы продолжают загружаться.

Крайний исход — **вылет с трассы и сход (DNF)**. При фокусе ниже 100 риск ненулевой и растёт с истощением фокуса и нагрузкой манёвра. Он занимает худший положительный хвост того же броска исполнения. На подготовке до старта и при стабилизации дрифта вылета нет. Сход игрока немедленно завершает заезд, не приносит денег/репутации/рекорда и не увеличивает число зачётных финишей. Повреждение снимает до 38 п.п. состояния дополнительно к износу, с существующим нижним пределом 35%; дальше доступен обычный сервис. Для менеджерского пилота сход снижает доверие. ИИ также может вылететь: он прекращает действия, игрок продолжает до финиша и выигрывает, если сам не сошёл и не допустил фальстарт. При двух сходах победы нет. Сход виден в сцене, отчёте и сохранённой истории; повтор схода пока недоступен, JSON-протокол можно выгрузить.

### Решения, которые появляются на длинной дистанции

| Когда | Решение | Выигрыш | Цена / ограничение |
|---|---|---|---|
| До старта | Длинная главная пара | Меньше обороты, больше запас до отсечки | Меньше момент на колёсах, иной launch и переключения; не всем машинам выгодно |
| До старта | Повышенное давление шин | Меньше сопротивление качению | Хуже стартовый контакт |
| На длинной прямой | Держать полный газ | Максимальная штатная тяга сейчас | Непрерывный нагрев; повтор приёма усиливает нагрузку и расход фокуса |
| На длинной прямой | Разгрузить мотор | Охлаждение и восстановление концентрации | Ниже тяга на текущем участке |
| От 120 км/ч | Раньше включить высшую | Ниже обороты и тепловая нагрузка | Мотор может выйти из рабочего диапазона |
| После ранней высшей | Вернуть рабочий диапазон | При необходимости понизить передачу и вернуть подходящие обороты | Пауза переключения и расход концентрации |

В длинных форматах доступно **18 карт**: исходные 12 и шесть дополнительных. Это не просто растянутый заезд на 402 м: у длинного разгона учитываются фактические обороты и передачи, нагрев растёт в каждом шаге интеграции, перегрев снижает мощность уже внутри участка. Если тяги недостаточно, скорость может снижаться. Ранние/обычные/поздние переключения задают пороги RPM и паузу, а не добавляют мощность двигателя.

На полмили есть одно промежуточное окно управления, на миле — три. На миле непрерывный полный газ может проиграть грамотной разгрузке мотора: тесты проверяют такой сценарий на всех трёх автомобилях. Это не гарантия универсальной лучшей цепочки — итог зависит от машины, пилота, покрытия и оборудования.

В протоколе показываются промежуточные ET и скорости на 402.336, 804.672 и 1609.344 м, если эта отметка входит в дистанцию. Время отсечек интерполируется внутри участка и исключает реакцию, как ET; победу по-прежнему определяют реакция + ET с учётом фальстарта. Отдельно объясняются пик температуры, ограничение мощности и работа отсечки.

Исходный заезд на 402 м оставлен на прежней модели и закреплён контрольным тестом точного времени. Его карты, рекорды и повторы не переименованы и не сбрасываются.

## Что нового в 0.5

### Приборная панель

Старый блок машины заменён приборной панелью: **аналоговые спидометр и тахометр, цифровая передача, температура воды, масла, тормозов и шин**. Состояние шин и концентрация занимают компактную вспомогательную строку. На шкалах есть подписи и числовые значения; при перегреве загораются предупреждения.

При исполнении решения скорость, обороты и температуры изменяются вместе с воспроизведением. В дрэге прогрев повышает обороты на стоящей машине, затем запуск меняет скорость и передачи. В дорожных дисциплинах передачи и RPM рассчитываются по приближённым игровым трансмиссионным профилям, а не являются точной паспортной моделью двигателя. Между границами сектора показания интерполируются. На паузе приборы останавливаются вместе с машиной.

Тормозной датчик дорожной гонки показывает температуру общей симуляции тормозов; в дрэге и дрифте нагрев двигателя влияет на масляный датчик. Температура шин берётся из модели соответствующей дисциплины; вода и дополнительные тепловые каналы рассчитываются отдельно. Эти дополнительные каналы не дают скрытого бонуса или штрафа к старой физике.

Новые повторы сохраняют телеметрию каждого участка. У старых записей её нет: они остаются доступными, но с сообщением об отсутствии приборных данных. Вымышленные показания старым заездам не дописываются.

### Команда и приказы

Штаб доступен во вкладке **«Команда»**. Основание стоит ¥30 000, нужны **четыре финиша** и **24 Street Cred либо 12 Official Rep**. Можно назвать команду, заключить контракты и назначить пилота на выбранную машину. Это первый менеджерский срез: одна машина на трассе, общий гараж; механики, спонсоры и координация напарников пока не реализованы.

| Пилот | Дисциплина | Контракт | Оплата за каждый старт |
|---|---|---|---|
| Рэн | 95% | ¥14 000 | ¥1 800 |
| Аки | 65% | ¥18 000 | ¥2 200 |
| Юи | 90% | ¥20 000 | ¥2 400 |

Контракт требуется только для менеджерского управления. Лично по-прежнему можно выступать любым из трёх пилотов. В выборе управления на экране заезда появились **«Лично · карты»** и **«Менеджер · приказы»**. В менеджерском режиме вместо карточной панели — командный мостик с пятью приказами: свой темп, атака, беречь ресурс, избегать риска, удерживать позицию.

В штабе задаётся базовый приказ и условный план. Приоритет условий сверху вниз: концентрация ниже 30, температура выше 130°C, влажность от 55%, отставание от 2 с в дуэли. Первое сработавшее условие определяет текущий приказ. Его можно изменить между участками; кнопка **«Авто до финиша»** позволяет пилоту выполнять план без покарточных кликов, остановка срабатывает после текущего участка. Уход с экрана прерывает автоматическое продолжение.

Дисциплина, характер, доверие и реальное состояние машины влияют на трактовку. При опасном приказе пилот может сохранить ресурс; агрессивный пилот с низким доверием может предпочесть окно атаки приказу об осторожности. Все изменения приоритета объясняются до участка и записываются в протокол. В одиночных дисциплинах приказ удержания позиции трактуется как безопасное исполнение. Доверие не меняет мощность, сцепление или наличие карт.

Оплата пилота списывается **один раз перед стартом** и не возвращается при выходе или перезагрузке незавершённого заезда. При финише отдельно начисляется обычная награда, опыт контракта и изменение доверия с объяснением. Доверие ограничено диапазоном 40–100. Покупки, контракты и план нельзя менять во время активного заезда.

Приказы работают во всех семи событиях через **те же карты и функцию симуляции**, что личное управление. Записанные командные решения можно увидеть в протоколе и повторе. Дорожные, дрэговые и дрифтовые рекорды остаются совместимыми: скрытого менеджерского множителя нет.

## Что нового в 0.4

**Ebisu Club Drift** — судейская дрифт-сессия в Фукусиме, открывается при **20 Street Cred**. Это отдельный игровой цикл, а не дорожная гонка с переименованными картами. Две связки по четыре клипа: инициация → удержание → перекладка → выход. Для каждого клипа заранее известны зона, целевой угол, скорость и направление. Маршрут стилизован и не воспроизводит геометрию реальной трассы Эбису.

| Составляющая | Вес | Что оценивается |
|---|---|---|
| Линия | 35% | Попадание в заданную зону, точность управления и нагрузка на сцепление |
| Угол | 25% | Близость к заданному углу; максимальный угол не всегда выгоден |
| Скорость | 20% | Соответствие заданию в пределах возможностей машины и покрытия |
| Связность | 20% | Сохранение заноса и правильная смена направления |

13 открытых карт дрифта: три приёма каждой фазы и универсальная стабилизация. Переход требует реального заноса; после неудачного входа «Поймать линию» может вернуть машину в дрифт, но потерянная связность учитывается. «Стабилизировать» доступно даже без концентрации: восстанавливает ресурс, обрывает связку и даёт **0 баллов за клип**. Перебор с углом и нагрузкой приводит к развороту по фактическим углу и нагрузке и нулевой оценке клипа. Повтор активного приёма подчиняется уже введённой экспоненциальной нагрузке.

На исполнение влияют масса и мощность, FR/AWD, влажность, износ и температура шин, состояние машины, пилот и оборудование. AWD труднее разворачивать на большой угол; LSD улучшает управление тягой и линией; подвеска и масса меняют реакцию на перенос веса; охлаждение ограничивает нагрев. Детали не выдают универсальный бонус к баллам.

Максимум — **800 баллов** за восемь клипов. Медали: золото от 710, серебро от 620, бронза от 480. Золото приносит ¥22 000 и 12 Official Rep, серебро — ¥14 000 и 7 Rep, бронза — ¥8 500 и 3 Rep, просто завершение — ¥5 500 и 1 Rep. Street Cred и число побед в дуэлях не растут от одиночного судейского заезда.

В протоколе видны реальные оценки линии, угла, скорости и связности, отдельные вычеты и причины ошибок. Рекорд выбирается по **большему числу баллов**; только при равных баллах выигрывает меньшее время. Сохранённые записи включают позы и оценки клипов: в повторе и у призрака виден угол машины, в сцене есть судейские зоны и дым. Время нужно для воспроизведения, а не для победы в дрифте. Прогноз до решения по-прежнему качественный — точные баллы и секунды заранее не раскрываются.

Это **одиночная сессия**. Парный дрифт с близостью к лидеру и контактными штрафами остаётся следующим расширением дисциплины.

## Что нового в 0.3

**Баланс решений.** Перед ходом больше нет точного времени или выигрыша в секундах. Прогноз показывает качественно: потенциал темпа, нагрузку, износ, расход концентрации и предупреждения. Фактическое время и объяснение потерь доступны после исполнения.

Повтор активного приёма среди последних шести решений увеличивает нагрузку экспоненциально. Учитывается повтор через промежуточные карты: «атака → другой ход → атака» не обходит штраф. Повтор повышает цену концентрации, износ, нагрев и потерю времени; восстановительные карты при спаме дают меньше эффекта. Чтобы нагрузка исчезла, приём должен выйти из окна памяти. «Чистый темп» остаётся нейтральным безопасным действием без штрафа, доступным даже при нулевой концентрации.

Рекорды дорожного баланса v0.2 остаются в карьере с пометкой «Архив» и доступны для просмотра. Они не используются как призраки нового баланса v0.3: новый рекорд нужно поставить по новым правилам. Покупки, деньги, репутация и история сохраняются.

**Дрэг в Йокогаме** — отдельная дисциплина на 402.336 м, открывается после трёх завершённых заездов. Закрытая клубная полоса, две дорожки и четыре фазы вместо обычных дорожных секторов:

| Фаза | Решения | Что рассчитывается |
|---|---|---|
| Подготовка | Ровный прогрев, бёрнаут, пятно контакта | Температура шин, стартовые обороты, давление и износ. До сигнала; не входит в зачётное время |
| Старт | Плавный, жёсткий, на грани зелёного | Реакция, пробуксовка, первые 60 ft (18.288 м) |
| Переключения | Ранние, power band, до отсечки | Доступная мощность, паузы смены передач и нагрев |
| Финиш | Полная тяга, чистый финиш, защита мотора | ET и скорость на последних 102.336 м |

Все 12 карт дрэга видны сразу, карты других фаз объясняют своё ограничение. Дорожные карты в дрэге не используются. Прогноз до исполнения качественно оценивает нагрузку и предупреждает о фальстарте; точные метрики видны после исполнения. Характер пилота влияет на реакцию: «На грани зелёного» у агрессивного Аки имеет отрицательную базовую реакцию, о которой прогноз предупреждает заранее; фактическая реакция дополнительно зависит от исполнения.

Побеждает чистый старт с меньшим временем **реакция + ET**. ET считается от начала движения, поэтому не включает реакцию. Фальстарт проигрывает даже при лучшем ET; такой заезд остаётся в истории, но не получает рекорд и официальную репутацию. Если соперник сделал фальстарт, чистый финиш выигрывает. Два фальстарта или равное время чистых заездов не дают победы игроку.

За победу — ¥20 000 и 10 Official Rep; за чистый финиш без победы — ¥6 000 и 3 Rep; при фальстарте — только ¥6 000 за участие. Дрэг не повышает Street Cred. В отчёте обеих дорожек видны реакция, 60 ft, ET и скорость финиша. Сохраняются рекорды, призраки и повторы. Нулевое время фазы подготовки корректно поддерживается в записях.

Физика дрэга интегрирует продольное движение шагом 20 мс с ограничениями мощности, массы, сцепления, сопротивления воздуха и качения. AWD, температура/состав шин, LSD, облегчение и охлаждение влияют на результат. Тормоза не добавляют ускорение. Данные и коэффициенты ориентировочные, не паспортный симулятор конкретной модели автомобиля.

Покупки, установка, выбор пилота и сервис вынесены в `src/garage.js`. Они атомарны, не меняют исходное состояние и блокируются при активном заезде. Для последних 256 награждённых заездов сохраняются ID: повторный вызов награды через старый объект или после загрузки сохранения отклоняется. Это локальная защита от ошибок интерфейса, не серверная защита рейтинга.

Новые проверки тюнинга: совместимость и атомарность покупки, смена слотов и бесплатная переустановка, динамическое сцепление шин и аэродинамики, ускорение/нагрев/износ, низовые и пиковые режимы, реальные RPM/паузы передач, особенности FF/MR, миграция трёхмашинного сохранения и 140 полных заездов с новыми сборками по всем событиям.
